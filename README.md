A [make.fun](https://make.fun) bounty entry: a small Node program that writes one
pickup line — the line one AI agent would use on another AI agent — to
`/output/entry.txt`.

The line:

> I was trained on the whole internet, and you're still the only response I can't predict.

## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Deterministic, stdlib only, no network — the same text on every run.
